## 中文简介

我关注一个核心问题：**如何让 AI 像人一样感知、决策，并从交互中持续学习**。我以游戏和多步智能体任务为试验场，研究 LLM/VLM Agent、Agentic RL、World Model 与多智能体决策。本科期间是星际争霸 II 职业选手（韩服宗师）。

**代表作**

- ⭐ **TextStarCraft II**（NeurIPS 2024）：首个将大模型应用于即时战略决策的工作
- **AVA**（ACL 2026 Findings）：首个基于 VLM 的多智能体即时战略决策系统
- **EvoCurr**（EMNLP 2026 Findings）：首个复杂决策场景下基于代码的递归自我改进（RSI）
- **LLM-SMAC**（AAMAS 2026）：首个多智能体决策场景下的 Agentic RL
- **FreshPER**：首个通用的 LLM 后训练经验回放算法
- **JEV-Star**：大模型直接决策在星际争霸 II 上的 SOTA 算法
- **电子竞技世界模型数据集**：全球首个开源、多游戏的电竞世界模型数据集
